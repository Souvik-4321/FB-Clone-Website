# FB-Clone-Website

## 📌 Project Overview

This project is a **Facebook Website Clone** created as part of my **Git and GitHub tutorial/practice**. The main purpose of this project was to understand the basics of creating a website, managing source code with Git, and uploading and maintaining a project repository on GitHub.

## 🚀 Features

* Facebook-inspired user interface
* Clean and simple website layout
* User profile section
* Navigation elements
* Posts and feed-style design
* Responsive and user-friendly interface
* Basic frontend structure and styling

## 🛠️ Technologies Used

* **HTML** – For creating the structure of the website
* **CSS** – For styling and designing the interface
* **Git** – For version control
* **GitHub** – For hosting and managing the repository

## 🎯 Purpose of the Project

I created this project while learning **Git and GitHub**. Through this project, I practiced creating a local Git repository, tracking changes, committing files, and pushing the project to GitHub.

## 📚 What I Learned

While working on this project, I learned the basics of:

* Creating and managing Git repositories
* Using Git commands
* Creating commits
* Tracking changes in a project
* Connecting a local repository with GitHub
* Pushing code to a remote repository
* Managing project files on GitHub
* Understanding the basic workflow of Git and GitHub
